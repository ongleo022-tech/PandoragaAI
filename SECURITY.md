# Signaler un problème de sécurité

Pour un problème de sécurité, évitez de publier des données personnelles ou des fichiers de mémoire JSON. Ouvrez une issue privée si la fonction est disponible sur le dépôt, ou contactez directement le mainteneur.

Pandoraga est un moteur d'échecs et n'est pas un outil de sécurité système. N'exécutez que des versions et fichiers dont vous comprenez la provenance.
